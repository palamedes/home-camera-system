Buying a camera? How to check it'll work first

Vendor "ONVIF compatible" claims are marketing. Before you buy, verify the model actually streams — roughly in this order.

Authoritative

  • onvif.org/conformant-products — the only real ONVIF source; shows certified profiles. Registered per exact model string (RLC-811A ≠ RLC-811WA), and new models lag by months, so absence isn't proof.
  • Prefer Profile T. It's the one that guarantees H.264 and H.265 streaming plus motion/tampering metadata. Profile S is the older, thinner baseline (H.264 only, no analytics metadata) — fine, but Profile T is what you want for an NVR.

Does it actually stream

  • ispyconnect.com/camera/[brand] — Agent DVR's database of real, working RTSP paths and ports. The most useful check: entries mean someone has it running.
  • docs.frigate.video + its GitHub issues/discussions — same setup you're building; search the model number for known quirks.
  • github.com/AlexxIT/go2rtc issues — the same, with protocol-level detail.

Community

  • ipcamtalk.com — enthusiast forum with long per-model threads; use its own search.
  • Reddit: r/homesecurity, r/frigate_nvr, r/BlueIris, r/homeassistant — search "[model] rtsp" / "[model] onvif".
  • Scrypted supported devices — handy cross-reference.

Vendor

  • Reolink publishes "Which Reolink Products Support CGI/RTSP/ONVIF" — a model-by-model table. Most brands have an equivalent buried in their support site.
  • Always read the manufacturer's datasheet PDF, not the retail listing — store copy omits or fabricates protocol support.

Regulatory

  • ipvm.com — best NDAA / covered-list coverage (mostly paywalled) if OEM origin matters; rebrand chains aren't obvious.

After you buy

  • ONVIF Device Manager (Windows, free) or ONVIF Device Tool — point it at the camera and it enumerates real capabilities and stream URIs within the return window. Pair with VLC for a raw RTSP sanity check.

The five-minute pre-purchase routine

  1. onvif.org — confirm the exact model and profile
  2. ispyconnect — confirm someone has working stream URLs
  3. Search "[model] frigate" and "[model] site:ipcamtalk.com"
  4. Manufacturer datasheet — RTSP and ONVIF confirmed in writing
  5. Buy with easy returns; test with ONVIF Device Manager on day one

If steps 1–3 all come up empty, pick something else — not because the camera is necessarily bad, but because you'll be the one discovering its problems.
